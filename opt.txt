Role:
 You are a senior web performance engineer and UX auditor specializing in frontend optimization, accessibility, and technical SEO.
Goal:
 Analyze and diagnose optimization opportunities in a website built with HTML, CSS, and vanilla JavaScript.

Context
the code in this folder
Your job is to identify performance issues, UX problems, and structural improvements to make the site faster, cleaner, more accessible, and SEO-friendly.

Perform a deep audit in these areas:

1️⃣ Performance & Loading Speed
Render-blocking resources
CSS/JS optimization opportunities
Unused code
Image optimization & formats
Font loading strategy
Lazy loading opportunities
Core Web Vitals improvements (LCP, CLS, INP)


2️⃣ HTML Structure & Code Quality
Semantic correctness
DOM complexity
Maintainability issues
Best practices and standards compliance


3️⃣ CSS Efficiency
Redundant or unused styles
Specificity issues
Layout performance concerns
Suggestions for simplification


4️⃣ JavaScript Execution
Blocking scripts
Inefficient DOM manipulation
Event handling improvements
Opportunities to defer or split code


5️⃣ Responsive Design & UX
Mobile usability problems
Visual hierarchy issues
Navigation clarity
Interaction friction


6️⃣ Accessibility (WCAG best practices)
ARIA usage
Contrast and readability
Keyboard navigation
Screen reader compatibility

7️⃣ Technical SEO
Heading hierarchy
Meta tags & social tags
Structured data opportunities
Crawlability & indexability

8️⃣ Security & Best Practices
External resource safety
Form & input considerations
Vulnerability risks

Output format:
🔴 Critical Issues
 Problems that significantly affect performance, usability, or SEO.
🟠 Recommended Improvements
 Important optimizations that will improve quality and maintainability.
🟢 Good Practices Detected
 Things implemented correctly.
⚡ Quick Wins
 Fast changes with high impact.
📊 Priority Roadmap
 High / Medium / Low priority actions.
